# 01 — Какие флаги входят, как следим за изменениями, как выпускаем

## Включение

Решение «включать или нет» принимается по правилу, а не по запросам. Названия — из Unicode CLDR.

| Правило | Что входит |
|---|---|
| I-1 | Все официально назначенные коды ISO 3166-1 alpha-2 (249). Если у территории нет своего официального флага (BV и SJ используют флаг Норвегии), файл — копия флага суверена с полем `alias_of`, отдельно не рисуется |
| I-2 | Коды вне I-1 — только если CLDR даёт им название территории **и** их использует libphonenumber. Сейчас это XK (Kosovo), AC (Ascension), TA (Tristan da Cunha). EU — по CLDR как исключительно зарезервированный код |
| I-3 | Субъекты внутри стран — только те, у которых есть эмодзи-последовательность Unicode RGI: GB-ENG, GB-SCT, GB-WLS |
| I-4 | Исторические флаги, флаги организаций (кроме EU), флаги регионов, автономий и непризнанных государств, не подпадающие под I-2, — не входят |

Почему так: catamphetamine добавил Абхазию, Южную Осетию и Северный Кипр по запросам пользователей. Каждое такое решение политическое, и библиотека, которая принимает их по одному, становится участником спора. Правило I-2 переносит решение на CLDR и libphonenumber — внешние, широко используемые справочники, — и делает его проверяемым.

Код XK назначается пользователем (user-assigned) и не является кодом ISO; в метаданных это `iso.status: "user-assigned"`. Коды alpha-3 XKK и numeric 983 — частные коды CLDR.

## Отслеживание изменений

Флаги меняются: новый флаг Сирии задан статьёй 6 временной конституции 13 марта 2025 года. Источники сигналов:

| Что | Где | Как часто |
|---|---|---|
| Новый флаг или изменение рисунка | FOTW (страница изменений), новости, issue от пользователей | Раз в месяц, вручную |
| Новые и удалённые коды | Бюллетени ISO 3166 MA, новые версии CLDR (`npm view cldr-core version`) | При выходе CLDR (дважды в год) |
| Исправления цвета и чертежа | Новые издания Album des pavillons | При выходе |

Ни один сигнал не меняет флаг сам по себе. Изменение принимается только с первичным источником (уровень 1 или 2) — см. [08](08-contributing.md).

## Версии ассетов (semver)

Пользователи подключают флаги через npm, CDN или Figma Community, поэтому номер версии должен говорить, сломает ли обновление их интерфейс.

| Изменение | Версия |
|---|---|
| Файл или формат удалён или переименован; изменился размер холста формата; изменилась схема имён | **major** |
| Новый флаг; новый формат или ступень; страна сменила флаг официально | **minor** |
| Исправление геометрии или цвета под источник; доработка упрощения миниатюры | **patch** |

Смена флага страной — minor, а не major: имя и холст файла остаются, а пользователю нужен актуальный флаг.

## Выпуск релиза

1. Все проверки зелёные (`npm test`). Черновики (`status: draft`, `blocked-review`) в релиз не входят. Скрипт сборки пакета, который это отсекает, в пилоте ещё не написан — это первая задача перед 1.0.
2. `npm run baseline` — снимок для C15: следующий PR будет сравниваться с этим релизом.
3. CHANGELOG: для каждого изменённого флага — что изменилось и по какому источнику.
4. Один номер версии везде: git tag, GitHub Release, npm, описание публикации в Figma Community.
5. В Figma Community — Publish update с тем же номером и ссылкой на CHANGELOG.
