# 07 — Проверки CI

`npm test` = `scripts/check.mjs` (все проверки) + `scripts/negative.mjs` (каждая проверка на сломанной копии). В GitHub Actions — `.github/workflows/ci.yml` на каждый PR и push в main; отчёт идёт в Summary, контактный лист и сломанные копии — в артефакты.

## Проверки

| № | Что | Откуда взялась |
|---|---|---|
| C01 | Для каждой страны и формата есть файл, лишних нет | durev-flags |
| C02 | Валидный XML, корень `<svg>` с xmlns | durev-flags |
| C03 | viewBox `0 0 W H`, width и height совпадают с форматом | durev-flags |
| C04 | Нет text, image, use, clipPath, mask, filter, style, script, gradient, pattern; нет stroke, clip-path, clip-rule, transform, href, opacity, fill-opacity | Durev: круг держался на clip-path, Figma его выбросила → 13 кругов выгрузились квадратами |
| C05 | У каждого path явные fill `#RRGGBB` и fill-rule; все подпути замкнуты; путь из нескольких подпутей — только evenodd | Durev: открытые subpath; нормализация c5525e5 сняла evenodd у 13 флагов, кольца рисковали стать дисками |
| C06 | Каждый fill — цвет из метаданных флага | Durev: палитра сверялась вручную |

| C15 | Визуальный дифф с `baseline/` (снимок прошлого релиза): отчёт об изменённых файлах, не ошибка | Durev: контактный лист «было/стало» в PR |

C10 зарезервирован под сверку чисел построения по контурам (сейчас это делают пробные точки).

## Сверка с Figma

Figma — мастер ([08](08-contributing.md)), поэтому в пилоте проверено, что Figma не меняет рисунок:

1. **Экспорт.** Все 300 вариантов выгружены из Figma как SVG и проверены на месте: нет clipPath, mask, g, transform; у всех путей evenodd; все подпути замкнуты; viewBox совпадает с размером. Две находки исправлены в генераторе: дробная ширина original (Figma округляет viewBox) и геометрия VA за холстом.
2. **Нормализация.** Экспорт Figma всегда добавляет `fill="none"` корню, `clip-rule` к путям и пишет белый как `white`. `scripts/normalize.mjs` убирает это без изменения геометрии. На двух настоящих выгрузках из Figma (`tests/figma-export/`) нормализованный файл проходит все проверки, исходный — нет (C04, C05).
3. **Пиксели.** `tools/figma-roundtrip.mjs` сравнил рендер каждого из 300 вариантов в Figma с рендером SVG из репозитория по внутренним пикселям: 0 расхождений на 2,2 млн пикселей. Контроль: подмена наборов даёт тысячи расхождений.

Не проверено: экспорт через REST `/v1/images` — для него нужен токен Figma. Первый запуск `export-figma.yml` покажет, совпадает ли он с экспортом плагина; проверки C01–C16 поймают расхождение.
