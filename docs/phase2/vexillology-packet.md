# Пакет для ревью вексиллологами (сгенерирован из data/flags)

Для каждого флага: что мы взяли за источник, какие числа построили и где сомневаемся. К пакету прикладывается контактный лист `preview/contact-sheet.png` и SVG из `flags/original/`.

## AU — Australia (Австралия)

- Пропорция: 1:2. Статус полного формата: ok.
- Источники: Flags Act 1953; Commonwealth Gazette No. 18, 23 March 1934 (описание) (уровень 1, прочитано: fotw); Australian Government, PMC: Australian National Flag (Pantone 280, 185); Style Manual 2002 (RGB) (уровень 1g, прочитано: fotw); FOTW: Australia, construction (уровень 4, прочитано: direct).
- Построение: Звезда Содружества: центр нижней четверти у древка, внешний диаметр 3/10 высоты. Южный Крест: смещения от центра вольной половины в долях высоты; внешние диаметры 1/7 и 1/12; внутренний радиус 4/9 внешнего.
- Вопросы:
  - Пробел: Схема из Flags Act 1953 и Gazette 1934 первично не прочитана; числа — по FOTW. Есть ли у вас первичный документ?
