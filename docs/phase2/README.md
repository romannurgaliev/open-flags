# Phase 2 — external review

Besides the author and Claude, four independent judges check the result.

| Judge | What it checks | Materials |
|---|---|---|
| The primary document | Geometry and color of the full formats | C09 compares probe points with the law's numbers on every PR ([07](../07-ci-checks.md)) |
| Users | Recognition of the miniatures against the alternatives | [recognition-test.md](recognition-test.md): plan and success threshold |
| Vexillologists | Accuracy of sources and construction | [vexillology-packet.md](vexillology-packet.md), generated from the metadata (`node tools/review-packet.mjs`): sources, numbers and specific questions for each flag |
| Native speakers and cultural experts | Whether simplified inscriptions, coats of arms and ornaments are acceptable | [native-review.md](native-review.md) |

## Sending the packet to vexillologists

1. Send `vexillology-packet.md` with the contact sheet `preview/contact-sheet.png` and the SVGs from `flags/original/`.
2. FOTW: the mailing list and the form on the site. FOTW collects source comparisons for each flag and a list of corrections to the Album des pavillons, so these are people already doing this work.
3. The Flag Institute (UK): its Union Flag specification is already used in the pilot for AU, NZ and FJ.
4. Ask for answers to the packet's questions rather than general feedback: each question is tied to a gap in the metadata.

An answer with a source closes a gap: the flag's `sources`, `construction`, `gaps` and status are updated.
