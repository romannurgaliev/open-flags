# Фаза 2 — внешняя проверка

Кроме автора и Claude результат проверяют четыре независимых судьи.

| Судья | Что проверяет | Материалы |
|---|---|---|
| Первичный документ | Геометрия и цвет полных форматов | C09 сверяет пробные точки с числами закона на каждом PR ([07](../07-ci-checks.md)) |
| Пользователи | Узнаваемость миниатюр против альтернатив | [recognition-test.md](recognition-test.md) — план, порог успеха |
| Вексиллологи | Верность источников и построения | [vexillology-packet.md](vexillology-packet.md) — сгенерирован из метаданных (`node tools/review-packet.mjs`), по каждому флагу источники, числа и конкретные вопросы |
| Носители языка и культуры | Допустимость упрощения надписей, гербов, орнаментов | [native-review.md](native-review.md) |

## Как отправить пакет вексиллологам

1. Пакет `vexillology-packet.md` + контактный лист `preview/contact-sheet.png` + SVG из `flags/original/`.
2. FOTW: список рассылки и форма на сайте. На FOTW собраны сравнения источников по каждому флагу и перечень исправлений к Album des pavillons — то есть люди, которые уже делают эту работу.
3. Flag Institute (Великобритания): его спецификация Union Flag уже использована в пилоте для AU, NZ, FJ.
4. Просить не общий отзыв, а ответы на вопросы из пакета: каждый вопрос привязан к пробелу в метаданных.

Ответ с источником закрывает пробел: в метаданных меняются `sources`, `construction`, `gaps`, статус флага.
